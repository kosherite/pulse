# Getting help with Pulse

- **🐞 Bugs → open a [GitHub issue](https://github.com/kosherite/pulse/issues/new/choose).** There's a template, and bugs are tracked, deduped and linked to fixes here. Include your **Pulse version**, **platform** and **strap model**, plus a **strap log** — Pulse runs entirely on your device, so without one we usually can't tell a real fault from a setup detail. (Android: **Settings → Strap → "Share strap log (for bug reports)"**; macOS: the **Live** screen → **Strap log** card → **Copy**/**Save…**.)
- **💬 Questions, ideas & how-you-can-help → [GitHub Discussions](https://github.com/kosherite/pulse/discussions).** Ask, share results, and see [exactly what data would move Pulse forward](https://github.com/kosherite/pulse/discussions/147).
- **📣 Setup help, tips & release news → [r/PulseApp](https://www.reddit.com/r/PulseApp/).** Every release is announced there too.
- **📖 Docs → the [README](README.md)** covers install (macOS Gatekeeper / Android Play Protect), pairing a WHOOP 5.0/MG, privacy, and importing your history.
- **📧 Other → thepulseapp@gmail.com**

Pulse is an independent, unofficial project — **not affiliated with WHOOP, Inc.** — and **not a medical device**.
